# Increasing Voice Input Usage in ChatGPT Mobile App

## Overview

This repository contains my product design case study completed as part of the NextLeap program.

The project explores why voice input adoption is low among Indian users on the ChatGPT mobile app and proposes solutions to improve discoverability, usability, and adoption of voice interactions.

The case study applies systems thinking, user research, and product prioritisation to identify key barriers and design solutions.

---

## Problem Statement

Although voice input is available on the ChatGPT mobile app, adoption among Indian users remains low.

In a mobile-first country like India, voice interaction has the potential to make AI more accessible, especially for users who prefer speaking over typing or who interact in regional languages.

The goal of this project is to understand the barriers to voice usage and design solutions that encourage users to adopt voice input more frequently.

---

## Project Milestones

### Milestone 1 — Systems Thinking & Market Landscape

Understanding the voice technology ecosystem and current product experience.

Key activities:

* Studied voice interaction trends in India
* Analysed ChatGPT mobile voice UX
* Evaluated comparable voice-enabled products
* Built a KPI tree to map business and product outcomes

Output:

* 3-slide analysis deck covering landscape insights, UX evaluation, and outcome metrics.

---

### Milestone 2 — User Research & Problem Framing

Identifying real user barriers to voice input adoption.

Key activities:

* Defined key ChatGPT user segments
* Selected a high-impact segment for research
* Conducted a survey with 30+ responses
* Interviewed 5–6 users
* Identified behavioural patterns and mental models

Output:

* User research insights
* Problem Framing Canvas defining the core barrier.

---

### Milestone 3 — Solution Design & Growth Strategy

Designing and prioritising solutions to increase voice usage.

Key activities:

* Generated multiple solution directions
* Prioritised the most impactful solution
* Designed user flow and wireframes
* Defined success metrics and growth strategy

Output:

* Annotated wireframes
* User flow
* Metrics framework
* AI-assisted prototype.
